## Quick Reference

### Deploy to Vercel (Frontend)
```bash
npm install -g vercel
vercel --prod
```

### Deploy to Railway (Backend)
```bash
railway login
railway up
```

### Deploy to Azure App Service (Free Tier)
```bash
az webapp up --name myapp --resource-group myrg --sku F1
```

### Deploy to Google Cloud Run
```bash
gcloud run deploy myapp --source . --allow-unauthenticated --region us-central1
```
